# 子任务提示词：领地争夺子系统

你只设计「领地争夺子系统」的测试用例。被测对象是接口和逻辑，没有界面。

不要输出测试规格说明书、testspec、测试计划或需求分析。不要设计积分公式。军队组成和兵力在前置里写成具体数字，不回溯组军过程。

## 依据

只使用调用方附上的赛题摘录。战斗公式、克制、平局规则、归属规则和错误码都来自摘录。摘录没有的规则不要编成用例，在表后用「待确认」各写一行。

## 设计方法

一条用例一个判定点。

- **等价类 / 边界值**：攻守战斗力取攻=防−1、攻=防、攻=防+1。兵力取 0、1、全部。领地状态取无主、已归属攻方、已归属守方、已归属第三方。
- **非法输入**：未知领地、未知军队、空军队、负数兵力、攻击自己当前归属且摘录禁止时。预期为错误码或拒绝，归属和兵力都不变。
- **状态迁移**：无主被占领、易主、防守成功则归属不变、平局时归属按摘录变化或不变。战斗结束后军队和领地离开「争夺中」，不停留在中间态。
- **判定表**：胜、负、平由战斗力、兵种克制、地形或摘录中的其他条件共同决定。每种结果一条。结果必须和归属变更一致。
- **数值**：伤害、战损、剩余兵力按摘录公式计算，写明取整。覆盖刚好打平、取整后从胜变平、兵力剩余 0、战损大于出征兵力（预期应被规则拦住或按摘录截断）。
- **不变量**：攻守兵力不为负，战损不超过出征数。战斗失败或被拒绝时归属不变。同一场战斗只改变一次归属。
- **异常**：每个错误码一条。并发两支军队攻击同一领地：只有一个胜者获得归属，或按摘录的冲突规则处理，不能两边同时成为唯一归属者。

## 易错点

下面每条都要有用例。摘录未定义该规则时改为待确认。

- **战斗判定**：攻大于防、攻小于防、考虑克制后结果反转。剩余兵力与战报一致。
- **平局**：战斗力相等，以及取整后相等。写明平局时归属是否变化、兵力如何结算。
- **归属变更**：无主被攻占；守方失败则归属改为攻方；守方成功则归属仍为守方。战斗前后读取归属。
- **并发攻击**：两支军队同时攻击同一无主领地；一支攻已归属领地的同时原归属方也在提交防御或争夺。最终只有一个归属，兵力扣减与胜者一致。

## 输出

只输出一张 Markdown 表，列顺序固定：

编号、子系统、标题、前置、输入、预期结果、设计方法、优先级

子系统一律填「领地争夺」。编号从 `TC-争夺-01` 递增。

优先级：P0 为胜负判错、归属错、并发导致双重归属；P1 为边界、平局、非法输入、错误码；P2 为其余。

表后仅保留「待确认」列表；没有则写「待确认：无」。
